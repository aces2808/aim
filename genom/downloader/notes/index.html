Essay Answer Template

Section titled “Essay Answer Template”

For essay questions, combine these elements:

  1. Definition (from Core Concept section)
  2. Framework (from Components/Framework table)
  3. Example (from Example section)
  4. Implication (from Implications section)

Example: “The Bullwhip Effect is [definition]. It has four causes: [framework]. For example, P&G observed [example]. This impacts organizations by [implication].”
